# YouTube Content Strategy Prompt Library

A curated collection of high-leverage AI prompts for growing, optimizing, and
monetizing a YouTube channel. Each prompt assigns the model a specialist role
(e.g. *Content Systems Engineer*, *SEO Specialist*) and asks for a concrete,
ready-to-use deliverable rather than generic advice.

## How to use

1. Pick the prompt that matches your current goal.
2. Replace every `[bracketed placeholder]` with your own details
   (topic, niche, metrics, price, etc.).
3. Paste it into your AI assistant of choice.
4. Treat the output as a first draft — edit for your voice before publishing.

## Placeholder reference

| Placeholder      | Meaning                                            |
| ---------------- | -------------------------------------------------- |
| `[Topic]`        | The subject of a single video                      |
| `[Niche]`        | Your channel's overall content category            |
| `[Price]`        | The price of your digital offer / product          |
| `[X]%`           | A specific metric value (CTR, AVD, etc.)           |

## Contributing

Add new prompts to `prompts/youtube-content-strategy-prompts.md`. Keep the
format consistent: a short title, a one-line description of the outcome, and
the full copy-paste-ready prompt in a fenced block.
